# GameShelf 🎮

GameShelf is a desktop game store and personal game library built with **Java Swing** and **SQLite**.

The project was created for learning and portfolio purposes, focusing on desktop development, local databases and user authentication.

## ✨ Features

- User registration and login
- Password hashing with BCrypt
- Local SQLite database
- Game store interface
- User game library
- Persistent login session
- Modern interface using FlatLaf

## 🛠️ Technologies

- Java
- Java Swing
- SQLite
- JDBC
- BCrypt
- FlatLaf
- Maven
